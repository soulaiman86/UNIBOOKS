# 📚 UNIBOOKS - Full-Stack E-Commerce & Mobile Marketplace

UNIBOOKS is a comprehensive full-stack marketplace designed for buying and selling new and used university books. It bridges web and mobile ecosystems, integrating an intelligent AI chatbot assistant.

## ✨ Key Features

- **Multi-Platform Access:** Responsive Web Application + Dedicated Mobile App.
- **E-Commerce Architecture:** Product catalog, user authentication, secure checkout, and order management.
- **AI Chatbot (Uniboot):** Intelligent assistant helping users search books and answer marketplace inquiries.
- **Robust Database Management:** Relational data persistence with PostgreSQL.

---

## 🛠️ Tech Stack & Architecture

- **Frontend (Web):** React.js, HTML5, CSS3, JavaScript (ES6+)
- **Mobile App:** React Native, Expo, TypeScript
- **Backend Services:** Node.js, Express.js
- **AI Service:** Python, Flask (Uniboot Chatbot)
- **Database:** PostgreSQL
